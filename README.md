## About

**Voice Assistant** is a Python and Flask-based application that allows users to interact with a computer using natural-language voice commands.

Instead of manually typing commands or opening different applications for simple tasks, users can speak their requests and receive responses through the interface and voice feedback.

The project was developed as part of the **Oasis Infobyte Internship (OIBSIP) – Python Programming Task 1**.

## Why This Project?

Voice-based interaction makes everyday computer tasks more natural and convenient.

This project demonstrates how speech recognition and command processing can be combined with practical services to create a useful assistant.

It also provides hands-on experience in connecting a Python backend with a modern web interface and external services.

## Advantages

- **Hands-free interaction** – Users can perform supported tasks without typing.
- **Natural communication** – Commands can be given in everyday language.
- **Faster access** – Common information and actions are available through simple voice commands.
- **Centralized assistant** – Multiple utilities are combined in one application.
- **Accessible interface** – Voice interaction can make basic computer tasks easier for users who prefer speaking.
- **Extensible design** – Custom commands and additional services can be added as the project grows.
- **Practical architecture** – Demonstrates interaction between frontend, backend, APIs, and external services.
- **Learning-focused implementation** – Covers several real-world software development concepts in one project.

## Key Features

- 🎙️ Voice input and speech recognition
- 🗣️ Text-to-speech responses
- 💬 Conversation-based interface
- 🕐 Current date and time
- 🔎 Web search
- 🌤️ Live weather information
- 🧠 General knowledge responses
- ⏰ Timed reminders
- ✉️ Email through SMTP
- ⚙️ Custom commands
- 🌓 System, Light, and Dark themes
- ⚠️ Speech-recognition error handling
