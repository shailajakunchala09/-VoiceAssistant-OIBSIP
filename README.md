## About the Project

**Voice Assistant** is a Python-based intelligent assistant that allows users to interact with an application using natural-language voice commands.

The system receives a voice command, recognizes the spoken input, determines the intended action, executes the required task, and provides the result through the interface and voice feedback.

The project combines a **Python backend, Flask, JavaScript, speech recognition, text-to-speech, API integration, SMTP communication, reminders, and configurable commands** into a single voice-first application.

The goal is to demonstrate how natural-language interaction can be connected to practical everyday actions through a lightweight and extensible application.

## Key Capabilities

### Voice Interaction

- Speech input through a microphone
- Natural-language command processing
- Text-to-speech responses
- Conversation-based assistant interface
- Clear handling of speech-recognition errors

### Information & Search

- Current date and time
- Web search
- Live weather information
- General knowledge responses

### Productivity

- Timed reminders with audible alerts
- Email sending through SMTP
- Custom commands using `commands.json`
- Configured link and portfolio shortcuts

### User Experience

- Modern voice-first interface
- Centered microphone control
- Conversation and response area
- Quick action tools
- Responsive design
- System, Light, and Dark themes
